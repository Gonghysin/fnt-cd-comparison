# FNT / FFT / 时域 三种静态色散补偿的对比仿真

创建于 2026-11-23。状态：**M0～M8 全部完成（2026-11-23）**。结论见第 8 节和 `仿真总结报告.md`；代码仓库：https://github.com/Gonghysin/fnt-cd-comparison 。第 2～4 节是开工前写的计划，与最终实现有出入的地方已在对应处标注。

## 1. 缘起与参考

- 来源：陈思宇师兄建议"做一下 FNT 的实现，以及和 FFT、时域方案的比较"，之后再做 AEQ（自适应均衡）。
- 主要参考：Xing 等，*Low-Complexity Chromatic Dispersion Compensation Using High-Radix Fermat Number Transform*，JLT 42(15) 5190（2024）。参数和基线按它的第 VI 节设定，结论用来核对。
- 后续衔接：Liu 等，*Low hardware-complexity IQ skew tolerant finite field and time domain hybrid adaptive equalization…*，Opt. Express 32(24) 43020（2024）。本阶段只做静态 CD，不做它的自适应部分。
- 书：余建军 3.4 节（色散补偿，式 3-63～3-70，抽头数公式 3-70）。已有的 `sim/dispersion-demo`（科研工作区）可复用其色散模型。

## 2. 仿真目标

### 要做的一件事

在 MATLAB 里用**同一条链路、同一组参数**，实现并比较三种静态色散补偿方案：

| 方案 | 说明 |
|---|---|
| A. 时域 FIR | 时域滤波器，抽头数随距离增长（式 3-70） |
| B. FFT-FDE | 频域均衡，overlap-save，FFT 位宽 12–16 位 |
| C. FNT-TrDE | 有限域频域均衡（费马数 $F_n=2^b+1$，D1 表示，QRNS 处理复数卷积），$b=8$（$F_3$）和 $b=16$（$F_4$） |

比较两个维度：**BER**（随传输距离、随位宽）和**复杂度**（1 位全加器数）。

### 做到什么程度

| 级别 | 内容 | 验收标准 |
|---|---|---|
| 最低 | 三种方案的**浮点版**跑通 | 无噪声时补偿后 BER 为 0（或 EVM 接近 0），不补偿时 BER 明显差；A、B 在抽头足够时结果一致 |
| 目标 | **位精确（定点）版** FFT 与 FNT，扫位宽和距离，并做复杂度计数 | 能复现 Xing 2024 的**定性**结论：FNT（$b=16$）接近浮点 FFT 且不劣于 16 位 FFT；FNT（$b=8$）与 12 位 FFT 相当；FNT 的全加器数明显少于 FFT（论文报告约省 62%（$b=8$ 对 12 位 SR）、51%（$b=16$ 对 16 位 SR）） |
| 扩展 | 接着做 AEQ | 师兄提到的下一步，范围另定 |

两条原则：
- 数值与论文不一致时**如实记录差异和可能原因，不调参凑结果**。
- 复杂度只做**计数模型**，不做电路综合。

### 本阶段不做

FPGA/RTL 实现、非线性、偏振和 PMD、IQ skew、实测数据、载波和定时恢复（假设理想）。

## 4. 仿真流程

```
PRBS → QPSK 映射 → 脉冲成形 → 光纤色散（频域施加）→ 加噪 → 接收滤波/重采样（2 SPS）
     → [色散补偿：A 时域 FIR | B FFT-FDE | C FNT-TrDE] → 下采样 → 判决 → BER
```

各补偿方案的处理要点：

- **A. 时域 FIR**：抽头由逆色散的冲激响应截取得到（只做了浮点版，**没有做系数量化版**）。抽头数以信号带宽估计（`cfg.td.nTap_Rs`）为主，式 3-70 的值（`nTap_bound`）是上界，作最大抽头数的参照（见第 6 节）。
- **B. FFT-FDE**：分块（块长 $B$、重叠 $P$）→ FFT → 乘预先算好的 $H$ → IFFT → 去重叠。定点版每层 FFT/IFFT 截 1 位防溢出，逐点相乘后去掉低位（Xing 第 VI 节）。**实际实现**：正向每层右移 1 位、逆向不缩放（`'fwd'`）；字面读法（逆向也每层右移，`'both'`）作为对照保留，见第 6 节。
- **C. FNT-TrDE**：分块 → 截位缩放 → 实部/虚部各一路 DFNT → QRNS 转换 → 逐点相乘 → QRNS 反变换 → IDFNT → 提升成有符号数 → 缩放还原 → 去重叠。要求卷积结果落在 $\pm(F_n-1)/2$。**D1 表示只在 `fnt_d1.m` 里实现并测试（M3），数值流程直接用取模整数运算，结果与 D1 相同；D1 只体现在复杂度计数里（b 位 D1 加法 = b 个全加器）**。

复杂度计数规则（取自 Xing 第 VI 节）：复数乘 = 3 次实数乘 + 3 次实数加；复数加 = 2 次实数加；1 次实数乘折合 $b/3$ 次实数加；$b$ 位实数加 = $b$ 个 1 位全加器。FNT 里乘 $2^k$ 为 0 次加法，乘 $(\sqrt2)^k$（$k$ 奇）按一次加减法计（Xing 表 III）。

| 与组里的口径对齐 | 信道模型等，等师兄资料 |
| Chen 2025 式 2 与实际位宽对不上的问题 | 做位精确 FNT 之前先弄清，来源见科研工作区待办 |
| **$b=8$ 的位宽方案（M4 发现）** | $q=257$ 只能装 $\pm128$。按"输入和系数各量化成整数、卷积结果必须落在 $\pm128$ 内"的直接做法，卷积值约按 $2^{x\_bit+h\_bit}\sqrt N$ 增长，$N\ge256$ 时系数只能取 2～3 位，系数太粗，误差大。Xing 论文说 $b=8$ 接近 12 位 FFT，我读到的部分没有给出实现它的位宽设定（图 3 只说 bit-cutting and scaling）。可能的差别：他们是否对滤波器做了别的限幅或缩放、是否允许部分溢出、是否用分段缩放。M6 已确认这个方案下 $b=8$ 不可用（BER $2\times10^{-3}$～$3\times10^{-2}$）。**仍未解决**，要问陈思宇师兄，或查 Xing 的补充材料 |

## 8. 结果总结与局限（M8）

### 8.1 做了什么

三种静态色散补偿（A 时域 FIR、B FFT-FDE overlap-save 浮点/定点、C FNT-TrDE $b=8/16$），在 56 Gbit/s QPSK、2 SPS、80～4400 km 下比 BER 和复杂度。M1～M5、M7 有验收脚本（`tests/test_m*.m`，全部通过）；M6 是 `run_ber_sweep.m`（约 50 s，图里不画 `'both'` 两条线，只在表里保留）；M7 的主脚本是 `run_complexity.m`（几秒）。

### 8.2 结论（都是本仓库的仿真结果，不是论文原文）

| 问题 | 结果 | 依据 |
|---|---|---|
| FIR（抽头数取 $2\times$ 估计值）、浮点 FFT-FDE 与理想逆色散差多少 | BER 无显著差别（$E_b/N_0=8$ dB，约 $2\times10^{-4}$） | M6 |
| 定点 FFT 要几位 | $W\ge14$ 与浮点无差别；$W=12$ 在 BER $10^{-4}$ 处多 0.11 dB。缩放用"正向每层右移 1 位、逆向不缩放" | M5、M6 |
| FNT $b=16$ 要几位输入/系数 | 6/6 位与浮点无差别（多 0.02～0.06 dB）；4/4 位多 0.9～1.4 dB | M4、M6 |
| FNT $b=8$ | **未复现**：BER $2\times10^{-3}$（80 km）～$3\times10^{-2}$（4400 km），$E_b/N_0$ 到 10 dB 也过不了 $10^{-3}$ | M4、M6 |
| FFT 复杂度计数是否可信 | 与 Xing 表 VIII 的 60 项逐位吻合（<0.5%） | M7 |
| FNT 复杂度 | $b=16$ 对 16 位 SR 省 51%～54%（论文约 51%）；$b=8$ 的 1D 部分比论文低 4%～5%，2D 部分比论文高 30%～34% | M7 |

一句话：**$b=16$ 的 FNT-TrDE 在 BER 上等同浮点 FFT，复杂度约省一半，与 Xing 一致；$b=8$ 的复杂度优势成立，但 BER 没做到论文说的"相当于 12 位 FFT"。**

### 8.3 局限（读结果时要带上）

1. **噪声模型是我设的**：只加高斯白噪声，按 $E_b/N_0$ 扫；论文的 OSNR/相位噪声/ADC 量化等都没有。工作点 8 dB 是我挑的。
2. **符号率、滚降系数、"时域方案"含义都是暂定值**（见第 6 节）；FIR 抽头数是我按带宽估的 $2\times$，不是论文值。
3. **只有单偏振、无激光器相位噪声和频偏**，色散量已知且精确，所以没做 Xing 图 20/21 的"色散估计误差容限"。
4. **FNT $b=8$ 的量化方案是我设的**（直接量化、输入限幅 $x_{max}=3$、系数按峰值缩放、位宽按距离搜）。论文可能有额外的缩放/限幅/分段处理，我没读到；结论"没复现"只对我这个方案成立。
5. **定点 FFT 的截位规则是我选的**：论文字面是"每层截 1 位，逐点乘后去掉低 $b$ 位"。我试了字面读法（`'both'`），结果很差（$W=12$ 完全失效），所以主结果用 `'fwd'`。论文的真实做法未知，$W=12$ 的结论可能偏悲观或乐观。
6. **复杂度计数**：FFT 部分已对上；FNT 的 1D 比论文低 2.5%～5%（原因没查），2D 没做 Xing 的优化所以偏高。没数模约简、D1 转换、FFT 的旋转因子表存储、控制逻辑。
7. **BER 统计量**：100 万比特，BER $<10^{-5}$ 时误码只有个位数，曲线在 $E_b/N_0\ge9$ dB 处是噪声；图上看到的"低于理论"是统计涨落。
8. 没做 AEQ（自适应均衡），这是下一阶段。
